# Checklist manual FINDARO (dirección)

Completar en un Mac real antes de declarar listo comercial. Marcar cada ítem.

## Instalación
- [ ] Abrir `/Applications/Findaro.app` (o `~/Applications`)
- [ ] Bundle ID `app.findaro.files`, versión visible en Acerca de
- [ ] Icono Dock = arte aprobado (no regenerado en CI)

## Navegación y clics
- [ ] Clic simple selecciona la fila correcta
- [ ] Doble clic abre exactamente esa carpeta/archivo (tras scroll)
- [ ] Omnibox ⌘L / breadcrumbs
- [ ] Favoritos y Ubicaciones

## Doble panel
- [ ] Activar 2 paneles; foco Origen/Destino claro
- [ ] Mover → / ← con selección
- [ ] Arrastrar entre paneles
- [ ] Drop desde Finder

## Transferencias
- [ ] Bandeja ⌘C/⌘X/⌘V
- [ ] Lote multiarchivo
- [ ] Smart Merge con conflicto + cancelar
- [ ] Fallo a mitad no deja estado corrupto (mensaje claro)

## FSEvents
- [ ] Descargar en Safari/Chrome → aparece sin F5
- [ ] Renombrar/borrar en Finder → se refleja
- [ ] Tamaños de carpetas se recalculan (no quedan eternamente en 0/antiguo)

## Privacidad / IA
- [ ] Voz: si no hay on-device, mensaje y no inicia
- [ ] Ollama conectado / desconectado sin romper reglas

## Actualizador (sin publicar)

- [ ] No instalar desde host no allowlisted

## Claro / oscuro
